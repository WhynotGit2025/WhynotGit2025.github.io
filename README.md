# Yifan Mei — Personal Homepage

The source for [whynotgit2025.github.io](https://whynotgit2025.github.io/), a bilingual academic homepage for Yifan Mei.

The site is intentionally dependency-free and built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
